# Security Policy

## Supported Versions

Only the latest release and the current `main` branch receive security updates.

| Version | Supported          |
| ------- | ------------------ |
| Latest  | :white_check_mark: |
| Older   | :x:                |

## Reporting a Vulnerability

We take the security of Sindri PDF seriously. If you believe you have found a security vulnerability, please do **not** report it via a public GitHub issue or discussion.

### Confidential Reporting
Please submit vulnerabilities confidentially through GitHub Private Vulnerability Reporting:

1. Navigate directly to [Report a Vulnerability](https://github.com/Sunkarr/Sindri-PDF/security/advisories/new).
2. Provide a descriptive title, vulnerability details, and steps to reproduce.

This creates a private, encrypted advisory workspace where we can discuss the issue and coordinate a fix without disclosing anything publicly prematurely.

### What to include in your report:
- A description of the vulnerability and its potential impact.
- Step-by-step instructions (or a minimal proof-of-concept) to reproduce the behavior.
- macOS version and Sindri PDF version tested.

### What happens next?
- You will receive an acknowledgement of your report within 48 hours.
- We will work on a fix and coordinate a release timeline before public disclosure.
