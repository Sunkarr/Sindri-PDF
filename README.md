## Highlights

- ⚡️ **Lightweight & Fast:** Native macOS implementation using Swift and PDFKit.
- 🎯 **Distraction-Free:** Clean, minimal user interface designed for reading and reviewing documents.
- 🔒 **Privacy by Default:** Zero analytics, zero network requests, no subscriptions.
- 📦 **Simple Installation:** Standalone `.dmg` app without messy installer wizards.
- 🤝 **100% Free & Open Source:** Licensed under the MIT License.

## Getting Started

### Download
Grab the latest release `.dmg` from the **[Releases](../../releases)** tab or via the [official website](https://sunkarr.github.io/Sindri-PDF).

### Building Locally

You will need a Mac with macOS Sonoma or later and the Swift toolchain (Xcode or Command Line Tools).

```bash
# Clone the repository
git clone https://github.com/Sunkarr/Sindri-PDF.git
cd Sindri-PDF

# Compile and launch the app
./build.sh

# Or build a distributable DMG
./create_dmg.sh
```
